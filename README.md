# ANN Binary Classification Using Make Moons Dataset

## Project Overview
This project implements an Artificial Neural Network (ANN) for binary classification using the synthetic make_moons dataset from Scikit-learn.

The objective is to classify two interleaving moon-shaped data groups using a neural network.

## Technologies Used
- Python
- Google Colab
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow
- Keras

## Dataset
- Dataset: make_moons
- Total samples: 1000
- Input features: 2 (X1 and X2)
- Output classes: 2 (Class 0 and Class 1)
- Noise: 0.2

## Model Architecture
- Input layer: 2 neurons
- Hidden layer 1: 16 neurons (ReLU)
- Hidden layer 2: 8 neurons (ReLU)
- Output layer: 1 neuron (Sigmoid)

## Project Workflow
1. Import required libraries.
